# CortexSpace — Roadmap

A self-hosted AI workspace that beats the incumbents on **speed** and **friction**,
while matching their feature set.

## v1 (done)
- [x] Streaming chat with multiple sessions
- [x] Providers: built-in demo, Ollama, OpenRouter
- [x] File workspace: tree, editor, agent read/write/search
- [x] Agent tool loop with human-in-the-loop **approvals**
- [x] Web search (DuckDuckGo / SearXNG) + page fetch
- [x] Python execution (opt-in, always approvable)
- [x] Command palette (⌘K), keyboard-first UX
- [x] Zero build step, single process, offline-safe UI

## v2
- [ ] Model fallback chains (e.g. Ollama → OpenRouter)
- [ ] Scheduled/automated agent runs
- [ ] PDF & DOCX export of notes
- [ ] Browser companion: send the active tab to the agent
- [ ] Multi-user with per-user workspaces
